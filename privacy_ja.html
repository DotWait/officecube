1適用範囲

本ポリシーは、DotWaitが公開するWindowsデスクトップアプリ「OfficeCube（オフィスキューブ）」（以下「本アプリ」）に適用されます。対象は全13ツール（Excel 結合/分割・大容量表示・テキスト整形・マスキング監査、PDF 結合分割・圧縮・黒塗り/透かし、Word→PDF レイアウト修正・要語チェック・書式統一・差し込み印刷、Markdown→PPT、請求書/振込控えのOCR仕分け）です。

本アプリは Microsoft Store から MSIX として配布されます。

2ローカル処理の原則（データは端末から出ない）

  • ファイルの読み取りは、システムのファイル選択で明示的に選択した場合、またはドラッグ＆ドロップした場合に限ります；
  • すべての処理（結合・分割・整形・マスキング・圧縮・OCR・形式変換）は端末のメモリとローカル一時フォルダーで実行され、処理後に一時ファイルを削除します；
  • OCRは同梱のローカルAIモデル（ONNX Runtime）を使用し、クラウド認識サービスを呼び出しません；
  • オフライン動作：ライセンス確認を除き、ネットワーク切断時も全機能を利用可能；
  • レジストリ未使用・常駐なし、アンインストール時にローカルデータも削除されます。

4端末に保存されるデータ

  • 設定：UI言語（簡体字中国語/繁体字中国語/English/日本語）、ライト/ダークテーマ、既定の出力先；
  • ジョブの状態と履歴（ファイル名と処理状態のみ）；
  • 請求書仕分けのローカル台帳（SQLite、認識フィールドを含む）；
  • 出力ファイルはお客様が指定した場所に保存され、アプリが複製を保持することはありません。

開発/公開前ビルドのPro体験スイッチは端末ローカルのみに保存されます。Store版ではMicrosoftのライセンスが使用されます。

5当社が収集しない情報

  • アカウント登録・ログインはなく、氏名・電話番号・メールアドレス等の個人情報を収集しません；
  • 第三者の広告・分析・クラッシュレポート・行動追跡SDKを組み込みません；
  • 広告IDの収集、プロファイリング、第三者への販売・共有を行いません；
  • 選択ファイルと無関係なフォルダーの読み取りやディスクスキャンは行いません。

6サブスクリプションと買い切り

Proには3つの選択肢があり、解放される機能は同一です：

  • 月額：月次で自動課金されます。Microsoftアカウントのサブスクリプションページでいつでも解約でき、期間終了後に無料版へ戻ります；
  • 年額：年次で自動更新され、解約ルールは月額と同じ；
  • 買い切り：一括払いで永久解放。機種変更時は「購入を復元」で復帰；
  • 期限切れ・返金後は無料版の制限（1回3ファイルまで・逐次処理等）に戻りますが、生成済みファイルとローカル台帳には一切影響しません；
  • 更新・返金・領収書はMicrosoft Storeのポリシーに基づきMicrosoftが処理します。

7第三者サービスとコンポーネント

  • Microsoft Store / Windows サービス：ライセンス・購入・更新；
  • 文書処理コンポーネント（OpenXML、PdfSharpCore、pdfium、PDFtoImage、SixLabors.ImageSharp、SkiaSharp、ClosedXML、NPOI、SQLite、RapidOCR/ONNX Runtime）はすべてローカルで動作し、オンラインテレメトリを含みません。

8データセキュリティ

ファイルは端末から出ないため、クラウド漏洩リスクは該当しません。機密性の高い出力ファイルはお客様自身での暗号化をお勧めします。暗号化PDF/Wordのパスワードは該当ジョブのメモリ内でのみ使用され、保存されません。

9子どものプライバシー

本アプリは一般的な業務効率化ツールであり、14歳未満の子ども向けに設計されておらず、個人情報を意図的に収集しません。
